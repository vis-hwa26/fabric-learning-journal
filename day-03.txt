## Key Understanding

A Fabric Lakehouse combines the flexibility of a data lake with the querying capabilities of a data warehouse.

It allows structured and unstructured data to be stored in one location and provides access through both Spark and SQL.

## Lakehouse vs Warehouse

| Lakehouse                           | Warehouse                         |
| ----------------------------------- | --------------------------------- |
| Mainly Spark-based                  | Mainly T-SQL-based                |
| Structured + unstructured data      | Structured data                   |
| Good for data engineering           | Good for BI/reporting             |
| Supports notebooks                  | SQL-first development             |
| Uses Delta Lake                     | Uses Delta format                 |
| Suitable for medallion architecture | Suitable for dimensional modeling |
